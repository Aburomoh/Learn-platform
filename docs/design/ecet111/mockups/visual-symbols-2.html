Negative-edge trigger

Demultiplexer

The mux mirrored: one data line in, selects from the bottom, outputs on the wide side. Only if Product confirms it is in scope.

Full adder, inside

Two half-adder blocks and one OR gate. Block level, so it needs no five-gate circuit.

One gate block with its equations, the flip-flops as symbols, feedback from Q back to the gates. The flip-flop being asked about takes the focus.
