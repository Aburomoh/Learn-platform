## Notes
- Teaching order differs from chapter numbering: Ch8 comes in week 5 and Ch5 (deadlock) before Ch4
  (scheduling). A platform path in syllabus order should follow the Fall 2025 order above.
- Week 16 lists Windows techniques, networking and TCP/IP commands; the Ch9 deck covers network
  concepts and security only, so those topics are lab material outside the source base.
- Lab topics (DOS and Linux commands, OS installation, troubleshooting) appear only as learning outcomes;
  no lab sheets are in the source base.
